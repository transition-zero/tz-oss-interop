# Never flag

A reviewer must not raise a comment that falls under a rule below.

Each rule comes from a comment the reader rejected on an earlier pull request.
`/review-fix-cycle` adds a rule here only after the reader approves the wording.
Edit a rule, or delete one, by hand at any time.

A rule here speaks to a reviewer. It does not say the code may do the thing. It
says a comment about the thing is not wanted.
